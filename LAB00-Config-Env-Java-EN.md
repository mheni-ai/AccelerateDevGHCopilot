# LAB 00 — Environment Configuration for GitHub Copilot (Java)

## Description
Verify prerequisites and configure your resources before starting GitHub Copilot exercises with Java.

---

## Environment Prerequisites
Your lab environment must be configured for Java development using Visual Studio Code and GitHub Copilot.
You must have access to a GitHub account with GitHub Copilot enabled.

---

### Step 1: Check Git
```bash
git --version
```
If needed, download Git from: https://git-scm.com/downloads

### Step 2: Check Java (JDK)
```bash
java --version
```
If needed, download a JDK from:
- OpenJDK: https://adoptium.net/
- Oracle JDK: https://www.oracle.com/java/technologies/downloads/

### Step 3: Check Maven
```bash
mvn --version
```
If needed: https://maven.apache.org/download.cgi

### Step 4: Check Visual Studio Code
Install VS Code + Extension Pack for Java.

Steps to sign in, activate, and use Copilot.
